葡眾客戶需求追蹤 App（PWA 版）— 安裝說明
==========================================

這是一個「網頁 App」（PWA）：放到網路上之後，用手機打開、加入主畫面，就會像一般 App 一樣有圖示、全螢幕開啟、沒網路也能用。不需要上架 App Store／Google Play。

資料夾內容
  index.html            App 本體
  manifest.webmanifest  App 名稱、圖示設定
  sw.js                 離線功能
  icons/                App 圖示
  （這些檔案要一起上傳，不要改資料夾結構）


一、把 App 放上網路（擇一，都免費）
----------------------------------
PWA 必須用 https 網址開啟才能安裝，所以要先放到網路上。

方法 A：Netlify（最簡單，拖拉即可）
  1. 用電腦打開 https://app.netlify.com/drop ，註冊或登入免費帳號
  2. 把整個資料夾拖進網頁
  3. 完成後會得到一個網址，例如 https://xxxx.netlify.app
  4. 可在 Site settings 改成好記的名稱

方法 B：GitHub Pages
  1. 在 GitHub 建立一個新的 repository，上傳資料夾裡所有檔案
  2. Settings → Pages → Branch 選 main → Save
  3. 幾分鐘後會得到 https://你的帳號.github.io/repository名稱/

方法 C：Cloudflare Pages
  1. https://pages.cloudflare.com → Create → Upload assets → 上傳資料夾


二、安裝到手機
--------------
iPhone：用 Safari 打開網址 → 下方「分享」→「加入主畫面」
Android：用 Chrome 打開網址 → 右上「⋮」→「安裝應用程式」或「加到主畫面」

安裝後從主畫面圖示開啟。第一次開啟需要網路，之後離線也能用。


三、資料存在哪裡？（重要）
--------------------------
・客戶資料只存在「這支手機的這個 App」裡，不會上傳到任何伺服器。
  放網站的服務（Netlify / GitHub）只放 App 程式，看不到你的客戶資料。
・別人打開同一個網址，看到的是他自己的空白 App，看不到你的資料。
・以下情況資料會消失：換手機、刪除 App、清除 Safari／Chrome 的網站資料。
  iPhone 上如果很久沒開，系統也可能清掉網站資料。
  → 請定期到「設定 → 匯出備份檔」，把備份存到雲端硬碟或傳給自己。
  → 換手機時：舊手機匯出備份 → 新手機安裝 App → 設定 →「從備份檔還原」。
・App 會在超過 14 天沒備份時提醒你。
・手機和電腦的資料不會自動同步；要在另一台裝置使用，請用備份檔還原過去。


四、更新 App
------------
修改 index.html 後重新上傳，並把 sw.js 第一行的 VERSION 改成 "v2"、"v3"…，
手機下次連網開啟時就會換成新版。客戶資料不受影響。


五、注意事項
------------
・產品名稱、規格、售價、SV 取自葡眾官網 uvaco.com.tw（2026/11/18），以官網公告為準。
・本工具為非官方工具。
・客戶的姓名、聯絡方式屬於個人資料，記錄前請告知客戶用途並取得同意，備份檔也請妥善保管。


六、行事曆功能（v2 新增）
------------------------
・待辦頁：「30 天內全部加入行事曆」一次把跟進、回購提醒、客戶行程匯入手機行事曆；每一筆也有 📅 按鈕可單獨加入。
・產品／客戶頁：每項產品需求下有「跟進加入行事曆」「回購提醒加入行事曆」。回購提醒預設排在預計用完前 3 天。
・客戶頁 →「📍 行程」→「＋ 新增行程」：設定日期、時間、長度、地點、目的、備註、提醒，可「儲存並加入行事曆」。地點可直接點開 Google 地圖。
・加入時可再改標題、時間、提醒。
  iPhone：會跳出「加入行事曆」畫面，按「加入」。
  Android：會下載 .ics 檔，點開後選日曆 App 加入；也可按「Google 日曆」。
・行事曆是「複製一份」過去：之後在 App 裡改了時間，請再按一次 📅 加入（大部分行事曆會更新同一筆；若出現重複，刪掉舊的）。
・Google 日曆連結無法帶入提醒時間，需在 Google 日曆裡設定。

已安裝舊版的人：重新上傳整個資料夾後，手機連網打開 App 一兩次就會更新成新版，原本的客戶資料不受影響。
